Privacy policy

Calendar Sync is a personal tool used by one person, its owner, on their own computer.

What it accesses

With the owner's consent, it reads the owner's own Google Calendar events and the list of their calendars, read-only (Google scopes calendar.events.readonly and calendar.calendarlist.readonly). It never creates, changes or deletes anything in Google Calendar.

Where the data goes

The events are saved only on the owner's own computer. They are not sent to any server operated by this tool, not shared with or sold to anyone, not used for advertising, and not used to train any model. The sign-in token is kept in the computer's own keychain.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, and the local files can be deleted from the owner's computer.
